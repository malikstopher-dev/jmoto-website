# JMOTO Premium Upgrade Pack

Prepared for the existing JMOTO Next.js website.

## Start here
1. Read `01_brand/BRAND_RULES.md`.
2. Give `07_prompts/JMOTO_MIMO_MASTER_PROMPT.txt` to Mimo together with this pack/repository.
3. Use assets in `02_desktop`, `03_mobile`, `04_services`, and `05_icons` as production website assets.
4. Treat `08_reference` as art direction/reference. Many of those images contain baked-in text and are NOT intended to replace semantic HTML content.
5. After Mimo finishes, use `07_prompts/JMOTO_SOL_FINAL_AUDIT_PROMPT.txt` for Sol.

Official slogan: **We’ll keep you bright.**
Site languages: **English + Portuguese**.
Portuguese should be suitable for Mozambique.
