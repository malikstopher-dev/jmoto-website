# JMOTO Premium Brand Rules

## Locked identity
- Company: JMOTO Electrical Services (PTY) Ltd
- Official slogan: **We’ll keep you bright.**
- Do not replace, rewrite, or translate the official slogan in the logo lockup. It remains English in both site languages.
- Languages: English + Portuguese (professional neutral Portuguese suitable for Mozambique).
- Markets: South Africa + Mozambique.

## Visual language
- Base: near-black #050505 / charcoal #101114
- JMOTO red: #E10600 to #FF2A20 accents
- White: #F5F5F5
- Steel: #A7A9AC / #45474D
- Controlled red glow only; avoid gaming/neon overload.
- Brushed-metal and industrial textures may be used subtly.
- Preserve logo proportions. Never recolour it into unrelated palettes.

## Typography direction
- Display: condensed industrial sans (e.g. Oswald / Archivo Narrow / Bebas Neue where appropriate)
- Body/UI: Inter / Geist / DM Sans
- Keep headings bold, compact and readable.

## Motion language
- GSAP-powered, purposeful motion.
- Electrical line traces, staggered reveals, mask wipes, depth parallax, image clipping, magnetic CTAs, card tilt, count-up only for verified numbers.
- Respect prefers-reduced-motion.
- On mobile reduce parallax and pointer-specific effects.
